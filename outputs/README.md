# outputs/ — experiment artefacts

This directory is ignored by git except for this file; every artefact here is
regenerated by a command from `scripts/`.  Validate a completed tree with:

```bash
uv run python scripts/check_outputs.py
uv run python scripts/check_outputs.py --require-analysis
```

## Per-backbone directory

`scripts/run_mlp.py`, `scripts/run_cnn1d.py` and `scripts/run_ft_transformer.py`
write the same layout under `outputs/<backbone>/` (`mlp/`, `cnn1d/`,
`ft_transformer/`):

| File | Content |
|---|---|
| `raw_results.csv` | one row per (seed, defense, attack, epsilon) |
| `mean_results.csv` / `std_results.csv` | seed mean and standard deviation per cell |
| `significance_tests.csv` | paired t-test and Wilcoxon results between defenses |
| `efficiency_raw.csv` / `efficiency_mean.csv` | training time, parameter count, inference latency |
| `attack_generalization.csv` | robustness to attacks not used in training |
| `adaptive_attack_raw.csv` / `adaptive_attack_mean.csv` | adaptive suite (`--adaptive-eval`) |
| `full_test_clean_*.csv` / `full_test_attack_*.csv` | full-test evaluation |
| `category_raw_results.csv` / `category_mean_results.csv` | per-attack-category recall (phi4 input) |
| `hyperparameters.csv` | every configuration field, grouped, with help text |
| `run_summary.json` | config, resolved device and dataset-split evidence |

## Analysis directories

| Path | Produced by | Content |
|---|---|---|
| `outputs/figures/` | `scripts/pareto_selection.py` | Pareto front, risk surface, epsilon evolution, theta sensitivity |
| `outputs/<backbone>/risk_profile_4d.csv` | `scripts/pareto_selection.py` | phi1–phi4, per-objective std, Pareto and admissibility verdicts |
| `outputs/decision_settings.json` | `scripts/pareto_selection.py` | confidence margin, admissibility thresholds, per-backbone verdicts |
| `outputs/phi4_cnn/`, `outputs/phi4_ft/` | `scripts/evaluate_phi4_*.py` | multi-seed worst-class-recall evaluation |
| `outputs/extended_analysis/` | `scripts/analyze_extended.py` | epsilon sweep, ROC, gradient-masking check |
| `outputs/transfer_matrix/` | `scripts/evaluate_cross_backbone_transfer.py` | cross-backbone transfer attack results |

The authoritative description of the experiment protocol is `README.md`
(`README.zh-CN.md`); `docs/verification.md` maps each manuscript table/figure
to the command that regenerates it.
